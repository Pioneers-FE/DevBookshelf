## 40장 이벤트

### 40.1 이벤트 드리븐 프로그래밍

이벤트 핸들러: 이벤트가 발생했을 때 호출될 함수

이벤트 핸들러 등록: 이벤트 발생 시 브라우저에게 이벤트 핸들러 위임하는 것

이벤트 드리븐 프로그래밍: 프로그램 흐름을 이벤트 중심으로 제어하는 프로그래밍 방식

### 40.2 이벤트 타입

마우스 커서를 HTML 요소 안으로 이동했을 떄

- mouseenter: 버블링 X
- mouseover: 버블링 O

마우스 커서를 HTML 요소 안으로 이동했을 떄

- mouseleave: 버블링 X
- mouseout: 버블링 O

HTML 요소가 포커스 받았을 떄

- focus: 버블링 X
- focusin: 버블링 O

HTML 요소가 포커스 잃었을 때

- blur: 버블링 X
- focusout: 버블링 O

change: input 과 달리 focus를 잃었을 때 사용자 입력이 종료되었다고 인식하여 발생

readystatechange: HTML 문서의 로드와 파싱 상태를 나타내는 document.readyState 프로퍼티값이 변경될 때

DOMContentLoaded: HTML 문서 로드 파싱이 완료 -> DOM 생성이 완료되었을 때

load: DOMContentLoaded 이벤트 발생 후 모든 리소스 로딩이 완료되었을 때

### 40.3 이벤트 핸들러 등록

#### 이벤트 핸들러 어트리뷰트 방식

```jsx
<button onclick="sayHi('Lee')">clickme</button>
<script>
  function sayHi(name) {
    console.log(name)
  }
</script>

```

이벤트 핸들러 어트리뷰트 값은 암묵적으로 생성될 이벤트 핸들러의 함수 몸체를 의미

오래된 코드에서 사용

#### 이벤트 핸들러 프로퍼티 방식

```jsx
<button>clickme</button>
<script>
  const $button = document.querySelector('button');

  $button.onclick = function() {
    console.log("click")
  }
</script>

```

이벤트 타깃, on이벤트 타입, 이벤트 핸들러를 지정하여 사용

이벤트 핸들러 프로퍼티에 하나의 이벤트 핸들러만 바인딩할 수 있는 단점

#### addEventListener 메서드 방식

```
이벤트 타깃.addEventListener(이벤트 타입, 이벤트 핸들러 [ 캡쳐 사용 여부 ])
```

```jsx
<button>clickme</button>
<script>
  const $button = document.querySelector('button');

  $button.addEventListener('click', function() {
    console.log("click")
  });
</script>

```

하나 이상의 이벤트 핸들러 등록 가능, 등록된 순서대로 호출

참조가 동일한 이벤트 핸들러를 중복 등록하면 하나만 등록

### 40.4 이벤트 핸들러 제거

addEventListener -> removeEventListener : 메서드에 전달한 인수가 동일해야함, 무명 함수인 경우 제거 안됨

함수 자신을 가리키는 argument.callee 를 사용하여 무명 함수라도 함수 내부에서 이벤트 핸들러 제거 가능

### 40.6 이벤트 전파

이벤트 전파: DOM 요소 노드에서 발생한 이벤트는 DOM 트리를 통해 전파

캡쳐링 단계: 이벤트가 상위->하위 방향으로 전파

타킷 단계: 이벤트가 타깃에 도달

버블링 단계: 이벤트가 하위->상위 방향으로 전파

### 40.8 DOM 요소의 기본 동작 조작

preventDefault: DOM 요소의 기본 동작을 중지

stopPropagation: 이벤트 전파 중지

### 40.9 이벤트 핸들러 내부의 this

이벤트 핸들러 어트리뷰트 방식의 this : window

이벤트 핸들러 프로퍼티 방식, addEventListener 메서드 방식의 this : 바인딩한 DOM 요소

화살표 함수 내부의 this: window
