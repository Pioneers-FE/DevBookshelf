## 41장 타이머

### 41.1 호출 스케출링

호출 스케줄링: 함수가 명시적 호출이 아닌 일정시간 경과 후에 호출되도록

타이머 생성 함수: setTimeout(한 번 만 동작), setInterval(타이머 만료마다 반복 호출)

타이머 제거 함수: clearTimeout, clearInterval

타이머 함수는 호스트 객체

js엔진은 싱글 스레드이기 때문에 타이머 함수는 비동기 처리 방식으로 동작

```jsx
setTimeout((name) => console.log(name), 1000, "LEE");

const timerId = setTimeout((name) => console.log(name)); // 두 번째 인수가 없으면 기본값 0으로 동작
clearTimeout(timerId);
```

```jsx
let count = 1;

const timeoutId = setInterval(() => {
  console.log(count); // 1 2 3 4 5
  if (count++ == 5) clearInterval(timeoutId);
}, 1000);
```

### 41.3 디바운스와 스로틀

짧은 시간 간격으로 연속해서 발생하는 이벤트를 그룹화 -> 과도한 이벤트 핸들러의 호출을 방지하는 프로그래밍 기법

- 디바운스: 짧은 간격으로 이벤트가 연속 발생하면 이벤트 핸들러 호출하지 않다가 일정 시간 경과 후 이벤트 핸들러가 한번 호출되도록

- 스로틀: 짧은 간격으로 이벤트가 연속 발생하더라도 일정 시간 간격으로 이벤트 핸들러가 최대 한번만 호출되도록
