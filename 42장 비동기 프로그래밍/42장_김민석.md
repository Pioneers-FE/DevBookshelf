## 42장 비동기 프로그래밍

### 42.1 동기 처리와 비동기 처리

js 엔진은 하나의 실행 컨텍스트 스택을 갖는다

동기 처리: 실행중인 태스크가 종료할 때 까지 다음 실행될 태스크가 대기하는 방식

- 실행 순서 보장
- 이 후 태스크들이 블로킹

비동기 처리: 실행중인 태스크가 종료되지 않더라도 다음 태스크를 곧바로 실행하는 방식

- 실행 순서 보장 X
- 이 후 태스크들이 블로킹 X

비동기 처리 방식으로 동작: setTimeout, setInterval, HTTP 요청, 이벤트 핸들러

### 42.2 이벤트 루프와 태스크 큐

이벤트 루프: js의 동시성을 지원, 브라우저 내장 기능

태스크 큐: 비동기 함수의 콜백 함수, 이벤트 핸들러가 일시적으로 보관되는 영역

이벤트 루프: 콜스택에 실행중인 실행 컨텍스트 여부, 태스크 큐 대기중인 함수 여부 반복 확인하여 콜 스택이 비어있고, 태스크 큐에 대기중인 함수가 있다면 순차적으로 대기중인 함수를 콜 스택으로 이동

비동기 함수 setTimeout 콜백 함수는 태스크 큐에 푸시하여 대기, 콜 스택이 비면 콜 스택 푸시되어 실행
