## 43장 Ajax

### 43.1 Ajax란?

Ajax: 비동기 방식으로 웹페이지를 동적으로 갱신하는 프로그래밍 방식, XMLHttpRequest 객체 기반으로 동작

전통적인 방식의 단점

- 변경할 필요가 없는 부분까지 HTML을 전송받아 불필요한 데이터 통신
- 처음부터 다시 렌더링, 깜빡이는 현상 발생
- 동기 방식이기 때문에 서버 응답까지 블로킹

Ajax의 장점

- 필요한 데이터만 전송 받음
- 다시 렌더링 하지 않음, 깜빡이지 않음
- 비동기 방식이라 블로킹 발생하지 않음

### 43.2 JSON

JSON: 클라이언트와 서버간 HTTP 통신을 위한 텍스트 데이터 포멧

JSON.stringify: 객체 -> JSON 포멧의 문자열로 변환(직렬화)

JSON.parse: JSON 포멧 문자열 -> 객체로 변환(역직렬화)

### 43.3 XMLHttpRequest

```jsx
const xhr = new XMLHttpRequest(); // 객체 생성
```

##### 요청 전송:

- open 메소드로 HTTP 요청 초기화
- setRequestHeader 메서드로 요청 헤더값 설정
- send 메서드로 요청 전송

readystatechange 이벤트: readyState 프로퍼티 변경마다 발생
