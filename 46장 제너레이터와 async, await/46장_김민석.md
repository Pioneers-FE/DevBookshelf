## 46장 제너레이터와 async/await

### 46.1 제너레이터란?

제너레이터: 코드 블록의 실행을 일시 중지했다가 필요한 시점에 재개할 수 있는 특수한 함수

- 함수 호출자에게 함수 실행 제어권을 양도 가능
- 함수 호출자와 함수의 상태를 주고받을 수 있다
- 함수 호출 시 제너레이터 객체 반환

### 46.2 제너레이터 함수의 정의

```jsx
function* tmp() {
  yield 1;
}
```

### 46.3 제너레이터 객체

제너레이터 객체 호출 시 제너레이터 객체를 생성하여 반환

제너레이터 객체는 이터러블이면서 이터레이터

### 46.4 제너레이터의 일시 중지와 재개

yield: 제너레이터 함수의 실행을 일시 중지, 키워드 뒤에 오는 표현식의 평가 결과를 제너레이터 함수 호출자에게 반환

next: yield 표현식까지 실행 후 일시 중지, 함수 호출의 제어권이 호출자로 양도, value(yield 표현식에서 yield 된 값), done(제너레이터 함수가 끝까지 실행 되었는지 여부 boolean 값) 프로퍼티를 갖는 이터레이터 리절트 객체를 반환

### 46.6 async/await

await 키워드는 async 함수 내부에서 사용, async 함수는 resolve하는 프로미스를 반환

await 키워드는 프로미스가 settled 까지 대기하다가 settled 상태가 되면 resolve 처리 결과를 반환

async 함수 내에서 catch 문을 사용해서 에러처리를 하지 않으면 async 함수는 발생한 에러를 reject 하는 프로미스 반환
